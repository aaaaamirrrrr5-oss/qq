# گزارش اولویت‌بندی — Site Manager 3.12.0-dev1 (بازنگری ۲)

مبنا: `FEATURE_AUDIT_FA.md` بازنگری ۲ (سورس + `php -l` + ماتریس مسیرها). سایت زنده وجود نداشت.
اولویت‌ها پیشنهاد من‌اند و با تصمیم شما قابل تغییرند.

## P0 — قبل از هر قابلیت جدید یا انتشار (امنیت، کوچک و کم‌ریسک)
1. **حذف کوپن:** بررسی `shop_coupon` بودن ID، capability (`delete_shop_coupon`) و confirm سروری (`:1194`).
2. **capability صریح روی ۲۸ مسیر بدون کنترل** — اول ۵ مسیر حذف‌کننده: `/users/{id}`, `/terms`, `/coupons/{id}`, `/plugins/action`, `/themes/action`؛ سپس `/users`, `/plugins/toggle`, `/tools`, `/options`, `/customers`, `/reports*`, `/gateways`, `/emails`, `/notify`.
3. **نصب/به‌روزرسانی افزونه و قالب:** `install_plugins`/`install_themes`/`update_*`، احترام به `DISALLOW_FILE_MODS` و محدودسازی منبع URL.
4. **`/dash` برای کلید `read`:** حذف مقادیر مالی از پاسخ کلید `read` یا برداشتن مسیر از allow-list.
5. **confirm سروری** برای حذف کاربر/افزونه/ترم/کوپن (امروز فقط UI تأیید می‌گیرد).

## P1 — الزامات قانونی پروژه که هنوز برآورده نیست
6. جایگزینی SQL مستقیم: `DELETE` خام transient در `/tools` و `$wpdb->update` در جست‌وجو/جایگزینی با API رسمی (`delete_expired_transients`، `wp_update_post`).
7. سازگاری ووکامرس: اعلام HPOS، هدرهای `Requires at least / Requires PHP / Requires Plugins`، تست روی WP 7.1.4 / WC 11.2.2 و یک نسخه قدیمی‌تر.
8. **زیرساخت تست Bridge:** تست‌های قبلی در بسته نیستند. PHP 8.3 هست ولی WordPress/MySQL نیست؛ تست واقعی نیازمند staging یا محیط تست وردپرس است.
9. Audit کامل: هویت کلید/کاربر، هدف، نتیجه.
10. گزارش‌های بدون سقف بی‌صدا (صفحه‌بندی/تجمیع) و ذکر ارز/منطقه زمانی.
11. کش GET در `localStorage` اپ: حذف مسیرهای مالی/سفارشی از کش یا رمزنگاری با Keystore و پاک‌سازی هنگام خروج.

## P2 — قابلیت‌های غایب که بازار انتظار دارد
12. مالیات و حمل‌ونقل (API رسمی WC).
13. UI نصب/جست‌وجوی افزونه و قالب (Backend آماده است؛ بعد از مورد ۳).
14. ویرایش ابزارک‌ها، به‌روزرسانی هسته، Site Health مبتنی بر هسته.
15. بکاپ/بازیابی (احتمالاً ادغام با ابزار بکاپ مستقل).
16. مقاوم‌سازی ورودی `users()` (`isset` برای `login/pass/role`).

## P3 — قابلیت‌های بزرگ
17. Adapter Customizer، سپس Redux/Kirki/ACF.
18. RBAC چندبعدی و گردش تأیید.
19. مرکز چندفروشگاهی و داشبورد تجمیعی.
20. دستیار هوشمند (نیازمند تصمیم درباره ارائه‌دهنده، هزینه و سیاست داده).
