# گزارش ارتقای تجربه کاربری 4.1

## هدف
ارتقای لایه تجربه کاربری بدون تغییر قرارداد API یا حذف قابلیت‌های قبلی؛ تمرکز بر خوانایی، بازخورد، ناوبری، موبایل و دسترس‌پذیری.

## تغییرات اعمال‌شده
- افزودن لایه طراحی `www/ux-pro.css` با توکن‌های ظاهری، گوشه‌ها و فاصله‌های هماهنگ.
- بهبود هدر چسبان با پس‌زمینه شیشه‌ای و حفظ خوانایی هنگام اسکرول.
- بهبود نوار ناوبری پایین، اندازه هدف‌های لمسی و نمایش حالت فعال.
- بهبود کنترل‌های فرم، placeholder، focus و حالت ورودی نامعتبر.
- تنظیم بهتر Bottom Sheet، اسکرول داخلی و ناحیه امن دستگاه‌های دارای بریدگی نمایشگر.
- طراحی واکنش‌گرا برای موبایل کوچک، تبلت و نمایشگر بزرگ‌تر.
- احترام به `prefers-reduced-motion` و حذف حرکت‌های غیرضروری برای کاربران حساس به حرکت.
- افزودن `www/ux-pro.js` برای اعلام محتوای پویا به صفحه‌خوان، وضعیت بارگذاری، عنوان صفحه و معناشناسی تب فعال.
- بارگذاری لایه UX جدید پس از CSSهای قبلی برای جلوگیری از override ناخواسته.
- افزودن تست رگرسیون `tests/ux-pro.test.cjs`.

## فایل‌های افزوده/تغییریافته
- `www/ux-pro.css` (جدید)
- `www/ux-pro.js` (جدید)
- `tests/ux-pro.test.cjs` (جدید)
- `www/index.html`
- `package.json`

## اعتبارسنجی
- `npm test`: موفق، شامل تست جدید UX Pro.
- `npm run check:js`: موفق.
- تست‌های موجود ترجمه، RTL/LTR، هندلرها، امنیت کلاینت، تم و مرکز کنترل نیز اجرا و موفق شدند.

## محدودیت اعتبارسنجی
- این مرحله تست خودکار مرورگر واقعی روی دستگاه‌های Android/iOS نیست.
- اسکرین‌شات و تست دستی روی چند اندازه نمایشگر، TalkBack، VoiceOver و کیبورد سخت‌افزاری هنوز انجام نشده است.
- کیفیت UX نهایی به بررسی عملی روی دستگاه و سایت WordPress واقعی نیاز دارد.
- این تغییرات ظاهر و تعامل کلاینت را ارتقا می‌دهد؛ قابلیت‌های backend یا افزونه PHP را اضافه نمی‌کند.

## گام بعدی پیشنهادی
بازطراحی صفحه‌به‌صفحه بر اساس سناریوهای واقعی: اتصال سایت، داشبورد، سفارش‌ها، محصولات، ویرایش محتوا، رسانه، به‌روزرسانی‌ها و مدیریت چندسایتی؛ سپس تست کاربردپذیری با کاربران و اصلاح نقاط اصطکاک.
